# Is Subsequence

**Difficulty:** `Easy`

## Problem

Given two strings s and t, return true if s is a subsequence of t, and false otherwise.

A subsequence is formed by deleting some (possibly zero) characters from t without changing the relative order of the remaining characters.

Read s on the first line and t on the second line of standard input, and print true or false to standard output.

## Examples

### Example 1

**Input**
```
abc
ahbgdc
```
**Output**
```
true
```

**Explanation:** a, b, and c appear in t in that same relative order (positions 0, 2, 5).

### Example 2

**Input**
```
axc
ahbgdc
```
**Output**
```
false
```

**Explanation:** There is no 'x' anywhere in t after the 'a', so the sequence cannot be matched.
